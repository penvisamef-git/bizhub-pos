# BizHub POS — desktop downloads

The BizHub POS counter app for **Windows** and **Mac**. Download it from
**[bizhubcambodia.com/#pos](https://bizhubcambodia.com/#pos)** or from the latest release here:

| Computer | File |
| --- | --- |
| Windows 10 / 11 (64-bit) | [BizHub-POS-Setup.exe](https://github.com/penvisamef-git/bizhub-pos/releases/latest/download/BizHub-POS-Setup.exe) |
| Mac (macOS 10.15+, Apple silicon & Intel) | [BizHub-POS.dmg](https://github.com/penvisamef-git/bizhub-pos/releases/latest/download/BizHub-POS.dmg) |

After installing, choose your business type and enter the link code from your BizHub dashboard
(POS devices → Link a device).

## First time opening it (test version, not signed yet)

**Windows** — if you see "Windows protected your PC", click **More info → Run anyway**, then **Next → Install**.

**Mac** — open the .dmg and drag BizHub POS into Applications. If the Mac says it can't check the app, click **Done**,
then go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to BizHub POS.
